# Kashyap Shingala — Data Analyst Portfolio

A static, responsive single-page portfolio built with semantic HTML and CSS. It has no build step, JavaScript, server-side code, or database.

## Run locally

Open `index.html` directly in a browser, or serve this folder with any static HTTP server. The Manus Preview uses port `3000`.

## Files

- `index.html` — page content and semantic structure
- `styles.css` — responsive layout, color system, dashboard-style visuals, and motion preferences
- `logo.svg` — chart-mark favicon and project identity graphic
- `manus-routes.json` — single-page route declaration for Preview

## Personalize

- Replace contact/profile details and resume copy in `index.html`.
- The resume listed GitHub profile URL but not individual repository URLs. Project links intentionally go to the profile (`github.com/kashyap-shingala`) rather than inventing repository destinations; swap each with its direct repository link when available.
- Dashboard illustrations are CSS-only visual previews, not screenshots or claims about additional project metrics.
- The page uses Google Fonts (Space Grotesk and DM Sans) when online and falls back to system sans-serif fonts when offline.
- Adjust the palette and spacing in the `:root` variables at the top of `styles.css`.
